## Remote-media test results (2026-11-08, scripted requests)

- 35 unique image URLs referenced by the site: **16 verified HTTP 200 (image) — including the official logo
  and all 9 page photos that power hero/about/activity slots. 19 returned 403 to scripted requests**
  (video thumbnails + 2 IG gallery photos); Meta's CDN rejects non-browser contexts for some signatures.
  Consequence: every <img> on the site has an automatic onerror fallback that swaps any failed thumb for
  the branded cloud placeholder — the site never shows a broken image, and the real video (with its own
  poster) still loads inside the Iframely embed. Regeneration: docs/research-sources/.
- Iframely: embed.js HTTP 200 · generator URLs return 200 for both platforms (tested with real permalinks).
- Canonical post URLs: all og-verified 2026-11-08.

## Limitations & honesty notes

1. **No browser automation exists in this environment** (no Playwright/Safari MCP) — interactive embed
   rendering inside a real browser could not be observed. The Iframely integration follows the official
   embed.js contract exactly (data-iframely-url = original post URL, iframely.load() after insertion,
   12s timeout → fallback card), and the embed path was validated end-to-end at the network level.
2. IG posts beyond the newest 12 are login-gated — documented, not scraped.
3. FB "Reels" tab is JS-rendered for anonymous visitors — reel IDs were instead recovered from Google's
   index of /videos/<slug>/<id> URLs and each one og-verified; nothing is guessed.
4. The user-provided sample URLs in the brief (fb reel 1104273765763702, ig DfKgrF3INIe) were checked:
   DfKgrF3INIe belongs to an unrelated marketing account — treated strictly as format examples, not content.
5. The FB "1 review / Dr. Roksana (DMC)" group post was located but its content is group-gated; no
   testimonial text was taken from it. Parent quotes on the site come only from the official reels' captions.
